# 1. Executive Summary (الملخص التنفيذي)

1. **الهدف:**
   إجراء فحص وقراءة شاملة وتدقيق صارم لكافة كيانات وبيانات المنهج الدراسي في منصة CodeK، ومقارنتها بوثيقة المصدر الأساسي المعتمدة لمنهج وزارة التربية والتعليم المصرية (`docs/curriculum/CODEK_CURRICULUM_SOURCE_OF_TRUTH.md`).
2. **النتيجة الأساسية:**
   - نموذج بيانات Prisma الحالي (`Curriculum`, `Section`, `Lesson`, `VideoAsset`, `Task`, `Exam`, `StudentLessonProgress`) **مؤهل معمارياً بنسبة 100% لاستيعاب المنهج الوزاري الرسمي (4 فصول و 14 درساً) دون الحاجة لأي تعديل على الـ Schema أو إنشاء أي Migrations جديدة**.
   - **المنهج الوزاري الرسمي الفعلي (الصف الثاني الثانوي - الترم الأول) غير موجود حالياً في قاعدة البيانات**؛ حيث أن الدروس المخزنة حالياً هي عبارة عن دروس بايثون تجريبية مبكرة أو سجلات مؤقتة تولدها اختبارات التكامل الآلية (`vitest`).
   - كافة سجلات تقدم الطلاب (107 سجل)، وتسليمات المهام (15 تسليماً)، ومحاولات الاختبارات (47 محاولة) تنتمي حصراً لحسابات طلاب تجريبية مستخدمة في اختبارات الـ Backend (`Omar Hassan` و `Youssef Ali`)، ولا توجد أي حسابات طلاب حقيقيين مهددة بالفقد.
3. **الاستراتيجية الموصى بها:**
   **Strategy C (Preserve Legacy + Create Official Canonical Curriculum):** الإبقاء على السجلات التجريبية الحالية دون مساس لضمان عدم كسر أي اختبارات انحدار برمجية، وإنشاء دورة المنهج الوزاري ككيان نظيف ومستقل بـ 4 فصول و 14 درساً معتمداً.

# 12. Recommended Strategy (الاستراتيجية الموصى بها)

### **نوصي باعتماد Strategy C — Preserve Legacy + Create Official Canonical Curriculum**

#### المبررات الفنية والعملية:
1. **سلامة الاختبارات (Test Suite Stability):**
   هناك 249 اختباراً آلياً ممرراً بنجاح، وبعض هذه الاختبارات تعتمد في سياقها على وجود أو إنشاء دورات مثل `Egyptian Baccalaureate Programming & AI` أو `Python Mastery Track`. الإبقاء على هذه السجلات وعدم حذفها يضمن بقاء جميع اختبارات الانحدار خضراء بنسبة 100%.

   إنشاء دورة مستقلة ونظيفة مخصصة للمنهج الوزاري بعنوان:
   `"البرمجة والذكاء الاصطناعي — الصف الثاني الثانوي (الترم الأول)"`

3. **سهولة الإدارة والتسويق للطالب:**
   يمكن تعيين هذه الدورة كدورة أساسية منشورة وربطها بالخطة الدراسية مباشرة، مما يمنح الطالب تجربة تعليمية واضحة ومطابقة للكتاب المدرسي الوزاري بنسبة 100%.
